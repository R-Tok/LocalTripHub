# README

## サービス概要
「あなただけの気ままなローカルツーリズムを計画してみませんか？」  
ユーザーが住む街や旅先で出会った"メジャーではないけれどオススメしたいローカルスポット"になるべく特化して共有する、旅行系CGMサービスです。
投稿者にとっては旅の記録や情報のシェア、閲覧者にとっては情報収集を目的とします。

## サービス開発背景
国内旅行や近場でのふらっとしたお出かけを趣味としている私ですが、人混みが特に苦手。最近のオーバーツーリズムなど、予想以上の混雑があると興ざめしてしまうことも少なくありません。  
そんな自分は、マップを眺めて全国の市町村を追いかけたり、まだ知らない町や駅でふらっと下りて何気なく街歩きをすることも好きです。有名ではない町であっても、地元住民のように歩き、その土地での生活を想像するのも旅行の醍醐味だと思います。

「〇〇町ってどこ？」「何もなさそう…」「あんまりイメージ湧かないなあ」
こうした反応が無くなるよう、ユーザーの皆さまが全国の自治体に関心を持って街の魅力を再発見するとともに、"混雑を避けながら、自分のお気に入り穴場スポットをユーザー同士でこっそり教え合う"ようなサービスが欲しいと思いました。

## サービスの利用イメージ
### ユーザー登録
[![Image from Gyazo](https://i.gyazo.com/edae9831b6abe1ca4a7a0735c784d1c6.png)](https://gyazo.com/edae9831b6abe1ca4a7a0735c784d1c6)  
ニックネーム、メールアドレス、パスワードを設定します。
XまたはGoogleアカウントを用いたSNSログインも可能です。

### 投稿閲覧
[![Image from Gyazo](https://i.gyazo.com/0602f4eab70477ac8183ce4560b70e06.png)](https://gyazo.com/0602f4eab70477ac8183ce4560b70e06)  
GoogleMap上に、登録されたスポットがピンで表示されます。
投稿された内容はサムネイル画像つきで一覧表示され、また各スポット毎に投稿一覧を表示するページもあります。

### スポット登録・投稿作成
[![Image from Gyazo](https://i.gyazo.com/c0e95ad681ce1cffaf9f2e203b8bf955.png)](https://gyazo.com/c0e95ad681ce1cffaf9f2e203b8bf955)  
新たにスポットを登録する際は、スポット名・所在地・カテゴリを入力します。
GoogleMap上をクリックまたはスポット名検索をすることで、座標や市区町村を自動入力できます。

[![Image from Gyazo](https://i.gyazo.com/82f91f24f0f3183ead3cb3432c7efcfc.png)](https://gyazo.com/82f91f24f0f3183ead3cb3432c7efcfc)  
スポットに紐づいた投稿を作成します。おすすめポイントなどを自由にお書きください。
1投稿に画像は10枚まで添付できます。

### 投稿状況マップ
都道府県別および市区町村別のマップは、投稿されたスポット数に応じて、GitHubの草のように濃く塗られていきます。  
「この辺りが全然塗られてないな… よし、自分が開拓してみよう！」「私の推しの〇〇町をもっと知ってほしい！」など活用しながら、"みんなで地図を塗りつぶしていく感"をお楽しみください。
[![Image from Gyazo](https://i.gyazo.com/3fe10badc11a96f92fa127c3aff71e68.png)](https://gyazo.com/3fe10badc11a96f92fa127c3aff71e68)  

### ブックマーク・リスト作成機能
[![Image from Gyazo](https://i.gyazo.com/89c1fef485b0d2fa1dbd3dc5c2ee4ee6.png)](https://gyazo.com/89c1fef485b0d2fa1dbd3dc5c2ee4ee6)  
投稿の保存リストを複数作成し、お気に入りの投稿を任意のリストへ保存できます。
情報収集のまとめにご活用ください。
